# Erudience Plugin v2 — one action

User command: `@Erudience linkedin image`. The internal orchestration performs evidence-backed LinkedIn B2B strategy, content plan, original creative, deterministic image rendering, technical and visual QA, controller and owner approval, then *separately authorised* Social OS draft handoff. No auto-posting.

This is a **skill + local helper scripts**, not a deployed 24/7 server, autonomous endpoint gateway, database service or LinkedIn analytics integration. The scripts are runnable where Python/Pillow are available; SQLite stores local evidence only. Current logo bytes are not bundled because authenticated download has not succeeded. No guaranteed superiority to Social OS or 100% correctness. Every mandatory gate is fail-closed.

Read `skills/erudience/SKILL.md`, `references/orchestrator-v2.md`, `references/gates-and-handoff.md`, `references/strategy-playbook.md`, `references/asset-and-font-policy.md` and inherited `references/master-command-v6.md`.
