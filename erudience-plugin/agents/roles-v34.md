# Specialist roles, input, output and verification

| Role | Input | Output | Gate |
|---|---|---|---|
| Business intelligence | verified portfolio | service map | no invented offer |
| Competitor research | public sources | 50-record target dataset | provenance and coverage |
| Buyer research | permitted buyer signals | persona and pain clusters | hypothesis separated from evidence |
| Market research | dated sources | trend brief | freshness and geography |
| Keyword research | topic and source data | typed keyword cluster | primary uniqueness and evidence |
| Search intent | cluster and buyer question | intent/funnel map | relevance |
| Topic intelligence | existing library and new ideas | scored, versioned topics | no destructive delete |
| Content strategist | topics and constraints | 7-slot weekly plan | one promotion |
| Funnel planner | personas and plan | TOFU/MOFU/BOFU allocation | stage/CTA consistency |
| Content writer | approved brief | original caption | no unsupported claims |
| SEO optimizer | draft and cluster | natural-language revision | no keyword stuffing |
| Editorial reviewer | draft and target audience | clarity verdict | actionable and understandable |
| Fact checker | source registry and claims | evidence verdict | independent source checks |
| Creative director | verified copy and brand | creative brief | brand constraints |
| Image producer | brief and permitted assets | actual render file | file existence |
| Brand QA | render and manifest | inspection receipt | verified logo/fonts/readability |
| Delivery controller | approvals and receipts | review package or authorized handoff | explicit scope, readback |
| Analytics | observed permitted metrics | descriptive report | no invented attribution |

## Non-negotiable instructions
No fabricated competitor metrics, buyer quotes, rankings, testimonials, ROI, service capability or client results. No claims of successful remote action without readback. Never store secrets in files or logs. Block unsupported external writes. Each agent records its source IDs, output hash and uncertainty; the controller validates rather than trusting agent self-certification.
