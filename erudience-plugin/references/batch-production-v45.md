# Erudience v4.5 — One content, one image, one review chain

Trigger: `erudiance_linkdin` (alias `erudience_linkdin`). On demand, create seven distinct topics and initialize seven independent jobs via `scripts/batch_guard_v45.py`. Each job must traverse the existing 17-stage ChatGPT checkpoint bridge, which delegates to the canonical `gate_chain_v41.py` validator. There is no autonomous background scheduling.

Do not generate a seven-panel collage as seven deliverables. Image-generation tools must be called for one approved content item at a time; request a standalone 4:5 portrait poster. Each output must be a distinct PNG file at exactly 1080×1350. If an image-generation tool produces another size, treat it as a draft and do not approve it; a verified local resampling step is permitted only if the image remains legible and uncut, and must undergo independent visual re-review. No cropping, stretching, or poster-copy truncation to force dimensions. Never copy the same image to multiple IDs.

For each content_id, lock exact caption/topic/keywords. The image plan carries that ID, full caption and content hash. The image builder carries the same ID and plan hash. A reviewer must inspect actual pixels at native and mobile size, compare rendered words to the approved poster text and verify the footer, colour and actual font files. A passing boolean without independently stored evidence is not sufficient. Failed reviews invalidate downstream receipts and return to the owning stage; maximum three corrections. The batch is READY_FOR_OWNER_REVIEW only if all seven distinct jobs pass all 17 gates and produce seven distinct individually verified PNGs.

ChatGPT tools are not automatically callable from Python; the host assistant must execute tools and submit receipts to the checkpoint bridge. Without executable tool integration or independent inspection, return BLOCKED/NOT_APPROVED, never simulated success. Supabase/Social OS are future integrations. No posting, scheduling, database writes or external mutations without separate owner approval.
